Personal portfolio site for Sharang Nimonkar, clinical programmer (SAS, R and pharmaverse, CDISC SDTM and ADaM).

**Live site:** https://sharangnimonkar.github.io

## What's on the site

- Selected projects from the [clinical programming portfolio](https://github.com/sharangnimonkar/clinical-programming-portfolio): the `classiccompare` and `descriptiveStats` R packages, an R Shiny AE safety dashboard, SDTM and ADaM programming, TLG generation, and a Python AI clinical data agent
- Skills summary and short background
- Contact links

All portfolio work uses public data (pharmaverseadam and CDISC pilot datasets). No employer or client material is included.

## How it's built

A single static `index.html` with inline CSS and a few lines of JavaScript. No build step and no dependencies apart from Google Fonts. It follows the visitor's light or dark system setting.

## Preview locally

Open `index.html` in a browser, or serve the folder:

```
python -m http.server 8000
```

Then visit http://localhost:8000.

## Deploying

The site is served by GitHub Pages from the `main` branch (root). Pushing a change to `index.html` updates the live site within a couple of minutes.
